Status / Hosts and targets

Platform work is in progress.

Kryon defines UI decisions in Ziran, while declared hosts perform platform effects.

Build gate

Native generation

Maintained Ziran UI modules generate and compile as C, C++, and Go in make. This checks code generation and native compilation; it does not establish complete graphical runtime behavior.

Working example

Headless SVG host

The Button example runs a persistent portable bundle across input frames, then writes and verifies SVG output without a display.

Working hosts

Native integration

Terminal, desktop, raylib, libdraw, Canvas2D, and semantic DOM hosts are implemented in Ziran. Linux package tests exercise native input and rendering on private displays; browser tests use private headless Chromium. Platform accessibility and broader widget coverage remain open.

Working host

Canvas2D browser

The Canvas2D host builds a packaged Ziran application through Emscripten and verifies pixels, input, fonts, textures, WebAudio, files, and lifecycle in private headless Chromium. Ziran’s .zib runner remains the portable non-graphical path.

Working host

Semantic DOM browser

The semantic DOM profile reuses Canvas2D rastering and reconciles committed Kryon semantics into browser elements. A private headless Chromium test checks tags, attributes, state, and stable identity; CSS-native layout remains future work.

Evidence

Follow the maintained tests

Use Kryon’s build guide, the headless example, and Ziran’s implementation status. Feature claims should be checked against those current gates.
