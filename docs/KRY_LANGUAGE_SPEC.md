# Ziran language

Kryon is a UI library written in Ziran. The former `.kry` language, KIR, and
its compiler are no longer part of this repository. Current source files use
`.zi`; Ziran owns the `.zir` representation and `.zib` bundle format.

See [Ziran's language direction](https://github.com/kryonlabs/ziran/blob/master/docs/LANGUAGE_DIRECTION.md)
and [implementation status](https://github.com/kryonlabs/ziran/blob/master/docs/IMPLEMENTATION_STATUS.md)
for the current language contract and its limits. See [Kryon's API](API.md)
for widget imports and host capabilities.

The removed Kry language specification remains available in Git history.
