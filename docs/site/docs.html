Documentation / Current architecture

Kryon is a library.

The language, compiler, .zir, and .zib belong to Ziran. Kryon supplies reusable UI behavior through normal Ziran imports. This page describes the current development checkout; the public source branches may lag until their next sync.

01 / Modules

What Kryon provides

Maintained src/ui/*.zi modules cover geometry, layout, style values, accessibility, input and text editing, retained tree behavior, and selected widgets such as Button, TextField, TextArea, Image, Progress, Dropdown, TabBar, Slider, Checkbox, and Toggle. Each module is checked as Ziran code. The module list is the build inventory; feature behavior varies by host and target.

Widget APIs are ordinary declarations. The intended image surface is Image(ImageProps); semantic images use its props and alt text. Host adapters implement platform effects without taking over widget decisions.

02 / Boundary

Where code belongs

Ziran

Source language, parser, checker, laws, standard library, checked IR, native backends, bundle linker, verifier, and portable runtime.

Kryon

Widget composition, layout, styling, interaction, accessibility, rendering policy, and platform adapter interfaces written in .zi.

Applications

Product screens, workflows, and state. They import Kryon only where a UI is needed.

03 / Verification

Current build gates

make checks the maintained modules, writes saved IR, generates C, C++, and Go, and compiles native outputs. make test runs source, saved-IR, and portable behavior tests without a display. The headless example runs a retained Button through a portable bundle and an SVG host.

Complete widget composition and rendering, native window integration, browser hosts, and downstream app cutover remain unfinished. See platform status and Ziran’s language status.
