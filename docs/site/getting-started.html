Get started / Tested example

Build Kryon with Ziran.

The current example is headless: a checked Ziran application imports Kryon widgets, runs four pointer frames, and writes an SVG without opening a window. The linked source and tests are maintained on the repositories’ master branches.

StepsCloneBuildRun exampleNext

01 / Repositories

Place the projects side by side

git clone https://github.com/ziranlang/ziran.git
git clone https://github.com/kryonlabs/kryon.git
cd kryon

Kryon’s default build expects the Ziran checkout at ../ziran. Use ZIRAN_DIR to choose another location.

02 / Library

Build and check

make
make test

The build emits checked .zir, C, C++, Go, and native archives for maintained modules. The test gate includes portable behavior and starts no display.

03 / Application

Run the example

make -C examples
make -C examples test

The example writes build/examples/ziran/hello.svg with idle, pressed, released, and clicked frames. Its tests compare source and saved-IR bundles and verify one click changes the label.

Know the current boundary

This headless path demonstrates the intended library and host split. Linux terminal and graphical hosts now have package tests. Platform accessibility, broader widget coverage, and downstream application migration remain in progress. For language syntax, start with the Ziran guide; for Kryon internals, use the library docs.
