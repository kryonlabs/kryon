Get started / Tested example

Build Kryon with Ziran.

The current example is headless: a checked Ziran application imports Kryon widgets, runs four pointer frames, and writes an SVG without opening a window. The linked source and tests are maintained on the repositories’ master branches.

StepsCloneBuildRun exampleNext

01 / Repositories

Install Ziran, then clone Kryon

git clone https://github.com/ziranlang/ziran.git
make -C ziran install-user
git clone https://github.com/kryonlabs/kryon.git
cd kryon

make install-user puts the ziran command in ~/.local/bin. Kryon’s build uses the Ziran revision locked in ziran.lock; set ZIRAN_ROOT to build against another checkout.

02 / Library

Build and check

make
make test

The build emits checked .zir, C, Go, and native archives for maintained modules. The test gate includes portable behavior and starts no display.

03 / Application

Run the example

make -C examples
make -C examples test

The example writes build/examples/hello.svg with idle, pressed, released, and clicked frames. Its tests compare source and saved-IR bundles and verify one click changes the label.

Know the current boundary

This headless path demonstrates the intended library and host split. Applications with a window use the terminal, desktop, raylib, browser, or Android hosts listed on the platform status page. For language syntax, start with the Ziran guide; for Kryon internals, use the library docs.
