Status / Hosts and targets

Platform work is in progress.

The old `.krb` renderer matrix described a retired stack. Kryon now defines UI decisions in Ziran and asks declared hosts to perform platform effects.

Build gate

Native generation

Maintained Ziran UI modules generate and compile as C, C++, and Go in make. This checks code generation and native compilation; it does not establish complete graphical runtime behavior.

Working example

Headless SVG host

The Button example runs a persistent portable bundle across input frames, then writes and verifies SVG output without a display.

Migration work

Desktop integration

Platform effects and selected raster paths exist, while complete native window loops, input integration, and full widget rendering remain unfinished.

Migration work

Browser and portable

Full browser host behavior and portable capability coverage are still being implemented. Ziran’s .zib runner currently supports a documented subset.

Evidence

Follow the maintained tests

Use Kryon’s build guide, the headless example, and Ziran’s implementation status. Feature claims should be checked against those current gates.
