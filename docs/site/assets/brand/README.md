# Kryon Labs mark

`mark.svg` is a clean vector reconstruction of proposal 01 in
`/mnt/storage/Projects/kryonlabs-logo-proposals/2026-09-26/01-modular-k.png`.
It keeps the selected block geometry and colors, without the raster texture or
wordmark baked into the proposal image.

The site uses the mark in its header and footer. `favicon.svg` adds an ivory
backplate for browser tabs; `favicon-32.png`, `favicon.ico`, and
`apple-touch-icon.png` are raster versions of it. `og.svg` is the editable social
card source for `og.png`.
