# Kryon apps in the browser

Owner, 2026-11-17: "update the kryonl/abs webiset to be able to play evrey
vapp on wthe web too".

The website's Apps page links every published Kryon web build (Werkzeug,
Inner Breeze, Jungle Academy, Arcade, Shovey, Apfelwurm, Choano). The
Components page runs all 101 examples live. These Kryon Labs apps have no
browser build yet. Each blocker is in the app, not in Kryon.

| App | Why it has no web build | What a browser build needs |
| --- | --- | --- |
| Terminal | Its sessions run a shell through a Linux PTY (`src/terminal_pty_linux.zi`). Browsers have no local shell. | A web profile whose session talks to a remote shell over a WebSocket, or a demo shell. |
| Browser | `src/http.zi` runs `curl` for every page request; a web page may only fetch sites that allow cross-origin reads. | A web profile that loads pages through a proxy, or one that opens only CORS-enabled and bundled documents. |
| GitHub | `src/transport.zi` forks `scripts/api.py`, which calls `gh api` for every request; `src/desktop.zi` sets X11 window properties. | A transport over Kryon's browser HTTP requests to `api.github.com` with a token the user pastes, and a web profile without the X11 calls. |
| Explorer | It manages the folders on the local disk and drags files out over XDND (`src/file_drag.zi`). | A web profile over the browser's private file system, or a read-only demo tree. |
| Task Manager | `src/model.zi` reads `/proc`; `src/app.zi` imports `kryon/SystemThemeHostLinux` and calls `XInitThreads` in every profile, so even its declared `web` and `shot` profiles fail to link (`XQueryTree`, `XGetWindowProperty`). | Import the Linux theme host only in the desktop host (`src/desktop_host.zi`), then a web model with demo data. |

Workbook already runs in the browser inside Werkzeug; its Apps entry is
Werkzeug. Rill is a desktop environment and Agent Lab has no Kryon UI, so
neither is listed.

When an app gains a web build, add it to `SiteWebApp` in
`examples/gallery/src/site_apps.zi`, give it a card image in
`examples/gallery/assets/apps/`, and move it from `DESKTOP_APPS` to
`WEB_APPS` in `tests/site_browser_test.py`.
