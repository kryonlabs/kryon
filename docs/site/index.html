Framework

Language, runtime, renderers

Kryon keeps app code small while still exposing the lower-level surfaces needed for serious native development.

Language

Write declarative .kry interfaces, compile through KIR, and generate C, JavaScript, or portable runtime artifacts.

Framework docs
