What The Harness Covers

  • Lowering: perf-text-input validates KIR, C, Go, and KRB outputs for the same .kry source. JS/web output is paused.
  • Retained typing: text_input_perf_test checks repeated keystroke frames under the retained UI core.
  • Precision path: text_input_precision_test focuses random fields, sends one character or backspace, and verifies the edited text after each frame.
