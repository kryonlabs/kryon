Kryon supplies widgets, layout, interaction, styling, and rendering decisions as ordinary Ziran modules. Ziran owns the language and compiler. Applications import Kryon when they need a UI.

01 / LANGUAGEZiran

General-purpose source, checked .zir, native generation, and portable .zib belong to Ziran.

02 / LIBRARYKryon

Importable .zi modules define UI behavior. Widget names have no special meaning to the compiler.

03 / PLATFORMHosts

Declared capabilities let platform adapters provide input, fonts, images, rasterization, and windows.

A checked button example.

The example imports Kryon’s Button and tree modules, runs a press and release in a portable bundle, and asks a separate headless host to write four SVG frames. No display server is required.
