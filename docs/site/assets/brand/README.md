# Kryon Labs mark

`mark.svg` is a clean vector reconstruction of Proposal 01, Modular K, from
the exploratory Kryon Labs logo rasters generated on 2026-09-26. The original
proposals, exact prompts, and provenance are retained in the local Kryon Labs
profile archive under `work/branding/logo-proposals/2026-09-26/`; they are not
tracked site assets. The reconstruction keeps the selected block geometry and
colors without the raster texture or wordmark baked into the proposal image.

The site uses the mark in its header and footer. `favicon.svg` adds an ivory
backplate for browser tabs; `favicon-32.png`, `favicon.ico`, and
`apple-touch-icon.png` are raster versions of it. `og.svg` is the editable social
card source for `og.png`.
