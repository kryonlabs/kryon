# Kryon check consolidation

The baseline is master immediately before this consolidation. Each row counts
its own entry points, so a Make target that delegates to a behavior script
appears in the Make prerequisite count and the script in the script count.

| Check surface | Baseline | After consolidation |
| --- | ---: | ---: |
| Direct `make test` prerequisites | 88 | 86 |
| `tests/ziran_*_test.sh` behavior entry points | 180 | 174 |
| Source policy invocations per full CI run | 10 | 2 |
| Full CI jobs, including matrix jobs | 9 | 9 |
| Pages build, verification and deployment jobs | 3 | 3 |

verifies that artifact, and deploys it only after verification.

## Coverage mapping

| Removed invocation | Retained coverage |
| --- | --- |
| Standalone typed-key behavior script | The consolidated Ziran text-input fixture runs its UTF-8 scalar, queue, edit-key and shortcut assertions together with the active-editor focus table. Both run on native C and ZX, from source and saved IR. |

## Local wall time

Means of three runs on Omega, each script through the behavior runner:

| Merged check | Old scripts | Merged script |
| --- | ---: | ---: |
| `ziran_focus_test` | 22.8 s | 11.8 s |
| `ziran_game_controls_test` | 7.4 s | 4.3 s |
| `ziran_text_area_layout_test` | 9.8 s | 5.1 s |
| `ziran_terminal_cells_test` | 0.1 s | 0.1 s |
| `ziran_geometry_test` | 0.7 s | 0.6 s |

Each widget merge saves one full matrix pass (IR, two bundles, native C and
two Go builds), about 19 seconds per run across the three. The last two ran
on the pinned Ziran 7fbc8152 and were already quick.

The previous text-input scripts ran sequentially in 4.206 seconds. The
consolidated script took 2.211 seconds on the same machine with the existing
native Ziran binaries. These measurements cover the text-input tests only.
