Get started

Your first idea,
on a real screen.

Write a small interface, compile it into a portable cartridge, and open it in a native window. This guide starts with the KRB subset on Linux.

Try it in your browser → Download hello.kry ↓
01 / Get the tools

A small toolkit to begin.

Download the native tools bundle for your system from Kryon releases , verify its published checksum, and extract it. On Linux, use a desktop session with SDL2 installed. The commands below assume the extracted bundle’s bin directory is on your path. 

# Run inside the extracted tools bundle.
export PATH="$PWD/bin:$PATH"
k2b --help
krb-sdl --help

The bundle includes the compiler ( k2b ), native window host ( krb-sdl ), and headless renderer ( krb-run ). To build tools from source, see the repository build instructions . Other hosts and their coverage are listed under Renderers .

02 / Write an interface

A greeting and a button.

Save this as hello.kry in a new working directory. The app block sets the title and dimensions. App declares the screen and its controls. 

#import "kryon.h"

app "Hello, Kryon" {
    size 480 280
}

App :: () #ui {
    Screen root: {
        Background((Color){247, 243, 235, 255})
        Text((TextProps){.bounds = {36,48,408,40}, .text = "Hello, Kryon", .font = Text24, .wrap = TextWrapNone})
        Button((ButtonProps){.bounds = {36,112,176,44}, .label = "Get started"})
    }
}

Text and Button each receive one props value. Their bounds give the position and dimensions. This first button is a visual control; adding behavior is a separate next step.

03 / Run it

From source to a window.

From the directory containing hello.kry , run: 

k2b --root . -o build hello.kry
krb-sdl --w 480 --h 280 build/hello.krb

You should see “Hello, Kryon” and a “Get started” button. Close the window to exit. To render a PNG without opening a desktop window: 

krb-run --w 480 --h 280 --png hello.png build/hello.krb

KRB supports a subset of the native interface surface. For full applications, the C runtime is the most complete path. The browser Playground compiles locally and previews supported KRB nodes; the JavaScript application target is currently paused.
